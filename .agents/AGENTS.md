# Edcenta Workspace Guidelines & Rules

## 1. UI & Design Copy Guidelines
- **No Developer/Design Jargon in User-Facing UI:** NEVER include internal design system terminology, developer methodology names, or implementation tags in user-facing UI copy, badges, or headings (e.g., NEVER render text like "Bento Box Grid Architecture", "Stitch DESIGN.md", or "Bento Compartment").
- **Customer-Centric Copy:** All headlines, section titles, subheadings, and badge text must be clean, natural, and customer-facing product messaging.
- **Zero Placeholder/Dummy Content:** Always fetch live pricing, subscription plans, user data, and classes from the backend server via GraphQL/Apollo instead of using hardcoded mock arrays.
